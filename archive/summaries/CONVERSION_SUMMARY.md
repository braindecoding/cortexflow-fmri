## 📄 **CARA KONVERSI KE PDF**

### **Dari HTML File:**
1. **Buka** `METODOLOGI_CortexFlow.html` di browser
2. **Tekan** `Ctrl+P` (Windows) atau `Cmd+P` (Mac)
3. **Pilih** "Save as PDF" sebagai destination
4. **Atur** margin ke "Minimum"
5. **Centang** "Background graphics" untuk styling
6. **Klik** "Save" dan pilih lokasi file

### **Dari DOCX File:**
1. **Buka** `METODOLOGI_CortexFlow.docx` di Microsoft Word
2. **Pilih** File → Export → Create PDF/XPS
3. **Atur** quality ke "Standard" atau "High"
4. **Klik** "Publish"
